# Code of conduct

Everyone should be able to ask a beginner question, disagree with a rubric, or submit a correction without being singled out. When reviewing a contribution, identify the specific assumption, example, or behavior you would change and explain why.

These expectations apply in issues, pull requests, reviews, and other project spaces. Harassment, threats, discriminatory remarks, and sharing someone’s private information are grounds for moderation. Use fictional names and anonymized scenarios in interview examples.

Use GitHub’s **Report content** action on the relevant comment or profile to report abuse privately to GitHub. For routine moderation, mention the maintainer on the affected thread when it is safe to do so. The maintainer may remove harmful content, lock a conversation, or restrict participation.
