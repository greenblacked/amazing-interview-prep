# Security policy

Report a suspected vulnerability privately. Open the repository’s [Security page](https://github.com/greenblacked/amazing-interview-prep/security) and choose **Report a vulnerability** if available. If the option is missing, open an issue asking the maintainer to enable private vulnerability reporting. Keep the vulnerability details for the private report.

Include the affected hostname or revision, the expected and observed behavior, and the impact. Reproduce with a disposable session and fictional notes. Remove tokens, personal notes, and identifying information from any logs or screenshots.

This policy covers the interview app and its deployment workflows. Use a normal issue for curriculum corrections, layout problems, and other bugs without a security impact.
